# Belegarchiv

Private Web-App (Google Apps Script) zum Fotografieren, Archivieren und Auswerten von Belegen und Rechnungen.

- Speicherung in Google Drive, Daten in einem Google Sheet
- Automatisches Auslesen per Claude API
- Gmail-Import, Garantie-/Fälligkeitserinnerungen im Kalender, Steuer- und Inventar-Exporte

Einrichtung: siehe [ANLEITUNG.md](ANLEITUNG.md).
Updates werden von Hand bei script.google.com eingefügt – die App lädt keinen Code aus diesem Repository nach.

Im Code sind keine persönlichen Daten oder Schlüssel enthalten – diese liegen ausschließlich im Google-Konto.
